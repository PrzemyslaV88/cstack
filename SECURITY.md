# Reporting security issues

Report a suspected vulnerability privately using GitHub's
[Report a vulnerability](https://github.com/PrzemyslaV88/cstack/security/advisories/new)
form. Include the affected version, reproduction steps, impact and a minimal
sanitized example. Do not publish real credentials, private source or customer data
in an issue or pull request.

cStack is an early-stage project. Security fixes target the current version on
`main`; older versions have no promised maintenance window. There is no guaranteed
response time or paid bug bounty.

Read [Security and trust boundaries](docs/SECURITY.md) for the worker sandbox,
isolated verifier, credential handling, review gates and delivery limitations.
